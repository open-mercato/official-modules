Add `@open-mercato/pdf-generators` — PDF document generation for Open Mercato sales modules.

Provides a template registry with internal/external split, `BaseDocumentService` for extending with custom templates, and built-in templates for sales quotes (sales-offer) and orders (order-invoice). Includes a preview panel widget, backend generate/preview API routes, and a plugin convention for registering templates from external modules.
